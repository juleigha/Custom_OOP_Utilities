# Non-Proprietary Utilities

A small collection of standalone code I've written at work that isn't tied to a specific employer's codebase or data.

## AutoTestDjangoSerializers.py

An automated test script that caught numerous bugs in the data returned by my team's Django REST API serializers.

## FormBuilder.cs

A lightweight form validation library for .NET. Our forms all needed the same basic data validation, and the repeated code was piling up across the codebase, so I built a small reusable library instead.
